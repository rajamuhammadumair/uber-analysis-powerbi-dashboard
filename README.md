# 🚖 Uber Trip Analysis Dashboard

An interactive Power BI dashboard that analyzes Uber trip data to provide insights into ride demand, booking trends, trip distances, revenue, and customer behavior through dynamic visualizations.

---

## 📌 Project Overview

This project showcases an interactive Power BI dashboard designed to analyze Uber trip data. The dashboard enables users to explore ride patterns, monitor booking performance, evaluate revenue trends, and gain actionable insights through interactive reports and visualizations.

---

## 🎯 Objectives

- Analyze Uber trip demand and booking patterns.
- Monitor revenue and trip performance.
- Explore trip distance and duration trends.
- Identify peak booking periods.
- Build an interactive dashboard for business insights.

---

## 📊 Dashboard Features

- Interactive filters and slicers
- Ride demand analysis
- Revenue tracking
- Trip distance and duration analysis
- Booking trend visualization
- KPI cards
- Interactive charts and graphs

---

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Business Intelligence (BI)

---

## 📈 Key Insights

- Identify peak ride demand periods.
- Monitor booking and revenue trends.
- Analyze trip distances and travel patterns.
- Compare ride performance across different time periods.
- Explore key operational metrics through interactive dashboards.

---

## 🚀 How to View

1. Download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Interact with the dashboard using filters and slicers to explore the Uber trip data.
